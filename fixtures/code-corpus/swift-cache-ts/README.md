# Swift Cache TS

Coordination primitives and market-data policy utilities for short-lived lookup workloads.

- Language: TypeScript 5.x on Node.js 20 or newer
- Build: `npm install && npm run build`
- Test: `npm test`
- License: MIT
- Runtime dependencies: none; TypeScript and Node type declarations are development dependencies

The source is an independently authored synthetic fixture. Modules are intentionally small enough to inspect separately, while the policy engines exercise caching, ordering, routing, reconciliation, audit, calendar, pricing, and telemetry call chains.
