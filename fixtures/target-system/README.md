# Target Workspaces

`commons-fileupload-java-skeleton` is the current retrieval and translation
target workspace. It preserves Apache Commons FileUpload 1.5 package layout
and tests while leaving selected Java method bodies intentionally incomplete.

`forexplore-csharp-workspace` remains a separate C# compilation fixture for
the existing Java-to-C# adaptation service; it is not part of the retrieval
dataset.
